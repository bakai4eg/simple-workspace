# Simple Workspace (`bakai4eg_PM`)

Веб-приложение для мониторинга и управления проектной деятельностью, созданное в рамках дисциплины «Проектирование ПО 2»[cite: 19].

Система позволяет структурировать задачи в рамках рабочих пространств (Workspaces), распределять их по этапам и визуализировать в трех различных представлениях в зависимости от текущих задач команды[cite: 19].

---

## 🚀 Основные возможности

* **Управление пространствами (Workspaces):** Создание рабочих пространств, добавление и управление участниками[cite: 19].
* **Гибкая визуализация задач (Паттерн Strategy):**
  * 📋 **Канбан-доска:** Классическое представление задач по этапам (`To Do`, `In Progress`, `Done`)[cite: 19].
  * 🎯 **Матрица Эйзенхауэра:** Сортировка задач по срочности и важности с поддержкой Drag-and-Drop[cite: 19].
  * 📊 **Диаграмма Ганта (Таймлайн):** Визуализация временных рамок и зависимостей с помощью библиотеки Frappe Gantt[cite: 19].
* **Безопасность и авторизация:** Токенная аутентификация и хеширование паролей по алгоритму SHA-256[cite: 19].
* **Аудит:** Логирование ключевых изменений по задачам[cite: 19].

## 🛠 Технологический стек

### Backend
* **Python 3**
* **FastAPI** — асинхронный веб-фреймворк[cite: 19]
* **SQLAlchemy** — ORM для работы с базой данных[cite: 19]
* **SQLite** — локальная СУБД (`pro_kanban.db`)[cite: 19]

### Frontend
* **Vanilla JavaScript (ES6+)**
* **Tailwind CSS** — стилизация интерфейса[cite: 19]
* **Lucide Icons** — иконки[cite: 19]
* **Frappe Gantt** — интерактивный график Ганта[cite: 19]

## ⚙️ Установка и запуск

1. **Клонируйте репозиторий:**
```bash
git clone [https://github.com/bakai4eg/simple-workspace.git](https://github.com/bakai4eg/simple-workspace.git)
cd simple-workspace

```


2. **Создайте и активируйте виртуальное окружение:**
```bash
python -m venv venv
# Для Linux/macOS:
source venv/bin/activate
# Для Windows:
venv\Scripts\activate

```


3. **Установите зависимости:**
```bash
pip install fastapi uvicorn sqlalchemy

```


4. **Запустите сервер:**
```bash
uvicorn main:app --reload

```


5. **Откройте приложение:**
Перейдите в браузере по адресу `http://127.0.0.1:8000`.

## 🗄 Структура базы данных

База данных включает основные сущности:

* `users` — пользователи и их учётные данные.


* `workspaces` & `workspace_members` — пространства и права доступа участников.


* `stages` — этапы выполнения задач.


* `tasks` — задачи с приоритетами, срочностью и сроками.


* `task_logs` — история изменений задач.
